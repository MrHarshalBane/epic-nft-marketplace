# AURA // Cyberpunk Web3 NFT Marketplace

A decentralized digital collectible marketplace built with high-performance Node.js/Express, TailwindCSS, and Web3 wallet simulation + MetaMask connectivity.

## 🚀 Features
- **Live Genesis Collection**: Curated cyberpunk, cosmic, anime, and abstract 3D NFTs with rarities (Rare, Epic, Legendary, Mythic).
- **Web3 Wallet Connection**: Connect with actual MetaMask or 1-click Demo Vault loaded with 24.5 ETH.
- **Minting Studio**: Create and list new NFTs on-chain with artwork generators, custom pricing, rarity tagging, and metadata.
- **Dynamic Bidding System**: Real-time counter-offers, escrow tracking, and provenance transaction histories.
- **Instant Buy Execution**: Seamlessly acquire exclusive art pieces.
- **Interactive UI**: Cyberpunk mesh gradients, live ETH tickers, search & filter tabs, confetti celebrations, and toast feedback.

## 🛠️ Local Development
```bash
# Navigate to project
cd epic-nft-marketplace

# Start server
node server.js
```
Visit: `http://localhost:3000`
